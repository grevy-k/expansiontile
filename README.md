# ExpansionTile Flutter Demo

A simple Flutter demo showing how the `ExpansionTile` widget can be used in a real-world Student Help Center / FAQ screen.

## How to run
1. Clone the repository
2. Open the project in VS Code or Android Studio
3. Run:
   flutter pub get
4. Start the app:
   flutter run

## Three properties demonstrated
- `title` → shows the main text of the tile
- `leading` → adds an icon at the beginning
- `initiallyExpanded` → controls whether the tile starts open or closed

## Widget description
`ExpansionTile` is a Flutter widget that expands and collapses to show or hide extra content.
